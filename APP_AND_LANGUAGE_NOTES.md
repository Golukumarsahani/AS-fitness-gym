# AS FITNESS GYM — update notes

1. Copy these files over your project (same folders). `index.html` (project root) now has the manifest + app tags.
2. `npm run build` (dist/ is old until you rebuild), then deploy. `public/sw.js` and `manifest.webmanifest` must be served from the site root.
3. Admin → Website content: change Home banner / Home photo / About photo / Logo (upload), owner name, Hindi + Hinglish hero text.
4. Admin → Settings → Language: choose default site language (English / हिन्दी / Hinglish).
5. Phone app look appears automatically after the user installs the site (Add to Home Screen / Install App). Browser visitors get the normal website.
